# IT3081 – Statistical Modelling Consultancy Project
## Student Attendance and Performance Analysis

This project holds everything developed so far for the IT3081 group consultancy
assignment: dataset, cleaning/EDA/modelling scripts, and drafted report
sections for Tasks 1–6.

## How to open this in VS Code

1. Unzip the project folder.
2. Open the folder in VS Code: `File > Open Folder...` → select `sm-project`.
3. Install the Python + Jupyter extensions if you don't have them already
   (VS Code will usually prompt you).
4. Open a terminal in VS Code (`` Ctrl+` ``) and set up the environment:

```bash
python3 -m venv .venv
source .venv/bin/activate      # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

5. Run the scripts in order:

```bash
python src/clean_data.py        # Task 3: cleaning
python src/eda.py               # Task 3: descriptive stats + plots
python src/task4_inference.py   # Task 4: statistical inference
python src/task5_modelling.py   # Task 5: predictive modelling
python src/task7_pca.py         # Task 7: PCA critical evaluation
python src/task8_bayesian.py    # Task 8: Bayesian methods critical evaluation
python src/task10_early_warning.py      # Task 10: risk scores, tiers, cost analysis
python src/task10_framework_diagram.py  # Task 10: conceptual framework figure
streamlit run src/task10_dashboard.py   # Task 10: interactive dashboard (pip install streamlit)
```

`clean_data.py` produces `data/Students_Performance_dataset_clean.csv`.
The other scripts read that cleaned file (via `src/model_prep.py` for
Tasks 4–5, and again directly in Tasks 7–8) and write plots to
`outputs/figures/` and result tables/logs to `outputs/tables/`. Tasks 6 and
9 are written discussions only — no script for either.
