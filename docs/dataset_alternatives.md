# Alternative datasets considered (for reference / appendix)

Kept here in case the group needs to justify why the chosen dataset was
picked over these, or wants a backup.

## Broad, many-variable options
- **Kaggle — Student Performance Factors** (lainguyn123). 6,607 rows, 20
  columns. https://www.kaggle.com/datasets/lainguyn123/student-performance-factors
- **UCI — Student Performance** (Cortez et al.). 395/649 rows.
  https://archive.ics.uci.edu/dataset/320/student+performance
  Mirror: https://www.kaggle.com/datasets/larsen0966/student-performance-data-set

## Few-variable, high-credibility options
- **UCLA OARC "Attendance" / poissonreg dataset.** 314–316 students, 4–6
  variables (gender, math, langarts, daysabs, prog). Classic Poisson/GLM
  teaching dataset — good fit for the GLM requirement in Task 5.
  https://stats.oarc.ucla.edu/sas/output/poisson-regression/


## Chosen dataset
`data/Students_Performance_dataset.csv` — see `03_task3_descriptive_analysis.md`
for full rationale.
